# Monolayer MoS₂ Photodetector – Numerical Modeling

This repository contains the Python code for the research project:

**“Numerical Modeling and Optimization of the Photoresponse of a Monolayer MoS₂ Photodetector Under Variable Optical and Electrical Conditions.”**

## Objective

To numerically model and optimize the photoresponse of a monolayer MoS₂ photodetector under different:

* Optical intensities
* Wavelengths
* Applied biases

## Method

The model uses **1D drift-diffusion and carrier continuity equations** to simulate carrier transport, generation, recombination, photocurrent, and responsivity.
